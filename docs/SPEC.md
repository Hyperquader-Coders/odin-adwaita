# Spec — odin-adwaita

## Packages

```
adwaita/   package adwaita: generated by runic from adwaita/rune.yml
```

Import through the `adwaita` collection: `import "adwaita:<package>"`.

## Surface

Every public declaration of the bound headers (libadwaita 1.5.0), named as runic names
them, plus the hand fixes in [PATCHED.md](PATCHED.md). Deprecated API is bound, because
`GLIB_DISABLE_DEPRECATION_WARNINGS` is set when generating.

## Version

The binding records the library version it was generated from. `make test` compares it
with the version macros of the installed headers and with the loaded library.

## Types from other bindings

`gtk4:gtk4`, `glib:glib`, `glib:gobject`, `glib:gio` and `pango:pango` supply every
foreign type; `adwaita` declares only its own. Widget constructors return `^gtk.Widget`
where the C API does.
