# Patched bindings

The bindings are generated by [runic](https://github.com/Samudevv/runic) from the C headers.
Regenerating overwrites hand fixes, so each is also pinned by a typed variable in the
package's `patched.odin`: a regeneration that drops a patch fails to compile there instead
of misbehaving at run time.

To regenerate, run `make generate`, re-apply every row below, and build the package.

`scripts/postprocess.sh adwaita` rewrites runic's output after every generation. The rules are
odin-gtk's (MIT, [LICENSE-odin-gtk.md](LICENSE-odin-gtk.md)), kept where they still apply to
runic 0.8.

| rule | reason |
|---|---|
| `^glib.char` and `[^]glib.char` become `cstring` | `gchar *` is a typedef'd char pointer, which runic leaves as a pointer to `char` |
| `TYPE_*` constants of the form `` `(adw_foo_get_type ())` `` become `foo_get_type` | macro text runic quotes as a string; `TYPE_FOO` then names the procedure |
| `DURATION_INFINITE` becomes `0xffffffff` | a C cast runic quotes |
| `MAJOR_VERSION`, `MINOR_VERSION`, `MICRO_VERSION` and `VERSION_*` lose their backticks; `VERSION` is deleted | the version test reads them as numbers; `VERSION` is `(1.5.0)`, not an expression, and `VERSION_S` carries it |
| `Foo :: _AdwFoo` is deleted and `_AdwFoo` becomes `Foo` | one name per struct |
| `gio.Application` and `gio.ApplicationClass` become `gtk.Application` and `gtk.ApplicationClass` | `GApplication` and `GtkApplication` both trim to `Application`, and runic picks one at random per run; `AdwApplication` derives from `GtkApplication` |
| `TabViewShortcuts` (`adwaita_flags` in `postprocess.sh`) becomes `TabViewShortcutsBit :: enum u32` of bit indices plus `TabViewShortcuts :: bit_set[TabViewShortcutsBit; u32]`; `TAB_VIEW_SHORTCUT_NONE` and `TAB_VIEW_SHORTCUT_ALL_SHORTCUTS` become constants of `TabViewShortcuts` | `{.TAB_VIEW_SHORTCUT_CONTROL_TAB}` instead of integer ORs; the size and bits are those of C; see DECISIONS §7 |
| `parameters: declared` in `adwaita/rune.yml` makes every procedure parameter `^T` (`T **` is `^^T`); only the 13 parameters of the procedures listed under `to.detect.arrays` are `[^]`; the parameters in `scripts/single-object-params.*.txt` are pinned once per type in `patched.odin` | runic writes `[^]T` for any pointer parameter whose name ends in `s` (`settings`, `bounds`, `focus`, `n_types`...), and `[^]^T` for `T **`; a `[^]` on one object lets a caller index past it. The arrays were chosen against the C headers and the gtk-doc `(array)` annotations; `scripts/check-generated.sh` fails if a `[^]` parameter is not in `arrays:` or a listed single object is `[^]` again. Function-pointer types are always `^T` in this mode, so `param_rules` in `postprocess.sh` gives their parameters the types runic's name guess wrote before (`[^]T`, which includes the real arrays: `colors`, `uris`, `pts`, `attribute_names`); a row that matches nothing fails generation |
| a procedure whose last C parameter is a `va_list` is not generated; the foreign block carries a `// name skipped` comment | runic drops a trailing `va_list` and marks the procedure `#c_vararg ..any`, which is a wrong call; the fork skips it, and `check-generated.sh` holds the list of skipped names. Real `...` procedures (`list_store_insert_with_values`) are bound |

`rune.yml` also ignores the `_*`, `*DEPRECATED*` and `*AVAILABLE*` macros and `ADW_VAR`.

Pins, in `adwaita/patched.odin`: `patched_breakpoint_condition_to_string` and
`patched_alert_dialog_choose_finish` (the `cstring` rule), `patched_application_new`
(the one-name rule), `patched_type_dialog` (the `TYPE_*` rule), `patched_duration_infinite`,
and the `#assert`s and `patched_application_window_new` for the `Application` rule.

`scripts/type-casts.sh` writes `adwaita/type_casts.odin`: `FOO` and `IS_FOO` for every
`TYPE_FOO :: foo_get_type` in `adwaita.odin` that is a class or interface (DECISIONS §6).

GTK, GLib, cairo, pango, graphene and gdk-pixbuf types come from their packages, not from this one.
